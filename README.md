# CodeBud 👨‍💻

**Your ultimate companion for competitive programming.**

CodeBud helps you stay on top of coding contests across popular platforms like **CodeChef, Codeforces, LeetCode, AtCoder, HackerRank, and HackerEarth**. Track live and upcoming contests in one place and never miss an opportunity to sharpen your problem-solving skills.

🏆 **Stay Updated. Code More. Compete Better.**
